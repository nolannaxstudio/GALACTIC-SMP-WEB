01

Données collectées

ZYRANEX peut collecter les ID Discord des utilisateurs, les ID des serveurs et les préférences du bot lorsque ces informations sont nécessaires au service.

02

Utilisation

Ces données sont utilisées uniquement pour faire fonctionner le bot, enregistrer les préférences utiles et assurer les commandes attendues par les utilisateurs.
